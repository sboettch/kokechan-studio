# Object 02: Timber Facade & Lattice Doors (木造ファサード・格子戸)

## Multi-Elevation Architectural Asset Package
This folder contains the complete, reference-grounded asset package for **Object 02** in the Kyojima Eki 15-object authoring sequence, fully compliant with `kyojima-eki-interpretive-3d-v2.json` and canonical fieldwork evidence (`sumida-expo-2023-exterior.jpg`).

### Assets Included:
1. `elevation-front-timber-doors.jpg`: Ground floor sliding koushi doors and 9-pane display window.
2. `elevation-front-upper-windows.jpg`: Second floor 3 window bays with AC outdoor unit.
3. `elevation-east-plaster-relief-mural.jpg`: Authentic Sumida Expo white curling sprout plaster relief (うずまきレリーフ) on the east wall.
4. `elevation-front-master.jpg`: Full two-storey front elevation master.
5. `canonical-fieldwork-master.jpg`: Canonical fieldwork photograph from Sumida Expo 2023.
6. `texture-east-mural.jpg`: Orthogonal power-of-two texture mapped to the 3D east wall quad.
7. `object-spec.json`: Machine-readable metadata and architectural constraints.
