## 3. Data Integration & Digital Twin Architecture
Each site in this master index corresponds to a dedicated archival package containing:
1. **Fieldwork Evidence Dossier**: Local reference imagery, rights clearances, and documentary records.
2. **Architectural Execution Sequence**: The step-by-step component rendering order.
3. **Multi-Tiered LOD Geometry**: Distant washi-paper chiaroscuro fallback (<120 tris), 2D head-on photographic plane, and high-poly 3D polygonal master.
