# Inclusive Languaging Protocol

See [AGENTS.md](./AGENTS.md) and [GEMINI.md](./GEMINI.md) for the full inclusive languaging protocol.

All copy in this project — UI labels, documentation, tooltips, metadata, bilingual text — must comply.

## Summary

- No AI ingroup jargon: avoid `spine`, `gate`, `pass` (unless a railway ticket), `leverage`, `cadence`, `synthetic`, `imputed`, `ground truth`
- Write for everyday visitors, neighborhood residents, local shopkeepers, and international guests
- Japanese (`ja`) and English (`en`) copy must carry equal warmth and dignity — no robotic literalism
- No filler words: *delve, tapestry, testament, beacon, nexus, paradigm, bespoke*
- Use direct, inviting, functional language at all times

## Quick Reference

| Avoid | Use instead |
|-------|-------------|
| spine / 背骨 (for roads, transit) | Main Corridor / Primary Railway Line / 主要幹線 |
| gate / 檻 (abstract) | limit / time budget / commute boundary / 上限 |
| pass (AI jargon) | Skip / Next / Review Step |
| leverage | direct support / community investment |
| cadence | schedule / rhythm / routine |
| synthetic (in public UI) | interpretive illustration / community reference model |
| imputed / imputation | modeled / reconstructed / referenced |
| ground truth | field verified / on-site record / documented reality |
| experiments passing through | neighbors, craftspeople, and ongoing community life |
